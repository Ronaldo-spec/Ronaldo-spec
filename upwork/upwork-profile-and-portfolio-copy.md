## Main Profile Overview

I help businesses analyze system issues, improve ERP/application workflows, build SQL-based reports, and turn operational problems into clear technical solutions.

I have 2+ years of experience across ERP business analysis, application support, web development, SQL reporting, user requirement analysis, troubleshooting, and technical documentation. My background combines hands-on programming experience with business-facing support, so I can work between users, developers, managers, and stakeholders.

My strongest areas include:

- ERP and application support
- SQL reporting and data validation
- Business process analysis
- Requirement gathering and workflow documentation
- Root cause analysis for system or transaction issues
- Excel, SQL, Python, and data analysis projects
- PHP, JavaScript, AJAX, MySQL, Laravel, and backend/API support
- Project documentation and Agile/Scrum support

I am best suited for clients who need someone who can understand business operations, inspect system or data problems, write reports, document workflows, and communicate solutions clearly.

## Best-fit Projects

I can help with:

- Creating or improving SQL reports
- Checking data inconsistencies in business systems
- Analyzing ERP/application issues
- Writing SOPs, flowcharts, and process documentation
- Supporting users during system implementation or feature changes
- Cleaning, validating, and analyzing operational datasets
- Building portfolio-style data analysis reports
- Supporting PHP/MySQL-based web applications
- Reviewing system requirements and translating them into technical tasks
- Preparing project documentation, risk notes, stakeholder communication plans, and retrospective summaries

## Work Style

I focus on clear problem definition, careful data checking, practical solutions, and direct communication. I do not only fix the issue; I explain what caused it, how it was fixed, what the impact is, and what should be monitored afterward.
